# 🤖 AI Cover Letter Generator

This is a simple AI-based web application that helps users generate professional cover letters using their basic details and job description.

I built this project as part of my internship learning in Web Development and AI Integration.

---

## 🚀 Features

- User-friendly form interface  
- Takes input:
  - Name  
  - Job Role  
  - Company Name  
  - Job Description  
  - Resume Upload (Optional)  
- Generates AI-based cover letter  
- Secure API key using .env file  
- Copy to Clipboard feature  

---

## 🛠️ Tech Stack Used

- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js, Express.js  
- API: Google Gemini API  
- File Upload: Multer  
- Version Control: Git & GitHub

## ⚙️ How to Run This Project Locally

1. Clone the repository

git clone https://github.com/diyagupta22/Ai-cover-letter.git


2. Go to project folder

cd Ai-cover-letter


3. Install dependencies

npm install


4. Create `.env` file and add API key

GEMINI_KEY=your_api_key_here


5. Start the server

npm start


6. Open browser

http://localhost:3000


---

## 🔐 Security

- API Key is stored in `.env` file  
- `.env` is added in `.gitignore`  
- Key is not uploaded on GitHub
